두 값을 모두 채우면 전송 시 X-Timestamp / X-Nonce / X-Signature 를 브라우저에서 자동 계산해 함께 전송합니다. 서명은 HMAC-SHA256(SECRET, "{ts}.{nonce}.{sha256(body)}") 규칙이며 값은 브라우저 메모리에만 존재하고 서버로 원본 그대로 전송되지 않습니다. 비워두면 SKIP_HEADER_VERIFICATION=true 모드에서만 정상 동작합니다.
